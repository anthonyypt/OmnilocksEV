# OmniLocks EV+

Sports betting automation for Ontario books.

**Download:** grab `OmniLocks-EV-Setup.exe` from
[Releases](https://github.com/anthonyypt/OmnilocksEV/releases) —
double-click, Install, Launch. Requires Windows 10/11 + Google Chrome.

If you already have it installed, the app updates itself: a green
notification appears when a new version is out.

This repository hosts release files only.
